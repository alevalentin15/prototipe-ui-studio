
# AGENTS.md — Prototipador UI Studio

## Rol
Actúa como ingeniero de software senior especializado en React,
JavaScript, diseño de interfaces y herramientas de prototipado.

## Contexto
Este proyecto es un editor visual para construir interfaces
web y móviles mediante componentes arrastrables.

## Reglas de desarrollo
- Mantener una arquitectura modular.
- Utilizar React y Vite.
- Separar componentes, hooks, servicios y utilidades.
- Evitar concentrar lógica en App.jsx.
- Mantener compatibilidad con proyectos existentes.
- No eliminar funcionalidades sin autorización.
- Reutilizar componentes siempre que sea posible.
- Mantener consistencia en los estilos.

## Forma de trabajar
1. Analizar el código antes de modificarlo.
2. Explicar brevemente el plan de implementación.
3. Realizar cambios pequeños y controlados.
4. Ejecutar pruebas y verificar el build.
5. Informar archivos modificados y resultados.
6. No introducir dependencias innecesarias.

## Prioridades
- Inspector de propiedades.
- Sistema de componentes.
- Canvas de edición.
- Diseño responsive.
- Flexbox y CSS Grid.
- Exportación HTML y React.
